# Изображения

Сюда положите реальные изображения. Ожидаемые файлы:

- `logo.png` — логотип студии (используется в хедере и футере)
- `og.jpg` — превью для соцсетей (Open Graph), 1200×630

Все фото-плейсхолдеры на сайте (компонент `Placeholder`) можно постепенно
заменять на `<Image src="/images/..." />` из `next/image`.
